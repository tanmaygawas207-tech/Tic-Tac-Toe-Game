# Tic Tac Toe Game

## Introduction

The Tic Tac Toe Game is a console-based C++ mini game developed using basic programming concepts such as arrays, loops, and conditional statements.

## Features

- Two-player gameplay
- Dynamic 3x3 game board
- Player X and Player O
- Win detection
- Draw detection
- Invalid move validation
- Replay option
- Console-based interface

## Technologies Used

- C++
- Arrays
- Loops
- Conditional Statements
- Functions

## How to Play

1. Player X starts the game.
2. Players enter a position from 1 to 9.
3. The selected position is marked with X or O.
4. The board is displayed after every move.
5. A player wins by placing three symbols in a row, column, or diagonal.
6. If all positions are filled without a winner, the game ends in a draw.
7. Players can choose to play again.
